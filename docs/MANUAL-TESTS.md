# Manual tests

_What only a person in Thunderbird can check. Use made-up cards in a throwaway address book first; the real address books can stay unchecked in the sidebar until the test cards behave._

## 0.1.9 first run

**Before you start:** Thunderbird must allow unsigned add-ons (Config Editor: `xpinstall.signatures.required` = false), as for OMEMO for Thunderbird. Once the add-on is on addons.thunderbird.net, it's signed and this isn't needed.

1. **Install.** Add-ons and Themes > gear > Install Add-on From File, pick `contacts-cleanup/dist/contacts-cleanup-0.1.9.xpi` (over an older one if you installed it). Thunderbird asks to allow reading and changing your address books. Expect no errors in the Error Console (Ctrl+Shift+J).
2. **Open it.** Its icon in the left sidebar (under Mail, Address Book, Calendar and the others; hover shows "Contacts Cleanup"). It opens as a tab. Also try the toolbar button and Tools > Contacts Cleanup (press Alt to show the menu bar): each brings up the same tab, never a second one. Restart Thunderbird once: the sidebar icon is still there.
3. **Test address books (imported, nothing to type).** The made-up cards are in `docs/test-cards/`: `Cleanup test.vcf` (17 cards) and `Cleanup test 2.vcf` (1 card). If an older "Cleanup test" book is still there, delete it first. Import each file the same way: Tools > Import (or the ≡ menu > Tools > Import), Import from a file, Import Address Books, "vCard file (.vcf, .vcard)", Continue, pick the file, choose **Create a new directory called "Cleanup test"** (or "Cleanup test 2"; Thunderbird names it after the file), Continue, Start Import, Finish.

   What's in "Cleanup test": Test Person and Test P (same email, Test P has a photo and an organization), a card with only the email `first.last@example.org`, Phone Only (a mobile number), the Roe household (Sam, Sammy, Pat, Patricia, Alex), Harry Example (a UK number), Office Example (a number with an extension), a card with first and last name but no display name (Nora Example), one with only an organization (Example Hardware), one with only `jdoe1987@example.org`, Chat Friend (a chat address already), No Prefix (a chat address without `xmpp:`) and Old Jabber (an old X-JABBER line). "Cleanup test 2" holds a second Test Person.

   Back in Contacts Cleanup (it updates by itself): in the sidebar under Address books, uncheck every book except "Cleanup test" and "Cleanup test 2".
4. **Duplicates.** Test Person and Test P show under Potential duplicates ("same email"). Click Review: both cards are checked. Keep one, change the Name if you like, edit one of the phone numbers (say, the last digit), and use "+ Add an address" to add a made-up address. Click Merge 2 cards. In the Address Book: one card with both numbers (one as you edited it, with its type unchanged), the new address and the organization. Then Undo (the message at the bottom, or Changes): both cards are back as they were.
4b. **A group that's several people.** The Roe household (Sam, Sammy, Pat, Patricia, Alex) shows as one group, "may be more than one person". Review: two of them are checked (Sam and Sammy, or Pat and Patricia), the rest not. Rename the merged card (Name, First name), then Merge. The page stays open on the other three: the other pair is checked; Merge again. Then Not duplicates for what's left (Alex and the two merged cards). Undo from Changes brings the cards back. Open the group again and click Delete on Alex's card: only that card goes, the page stays, and Undo in the message brings it back.
4d. **Photos.** "Test P" came in with a photo (a teal circle). In Contacts Cleanup it shows in place of the initials. (If it doesn't show in the Address Book either, give Test P any small picture there.) Review the Test Person group: step 3 has a Photo choice; keep Test Person (no photo), pick Test P's photo, and Merge. The merged card in the Address Book has that photo. Undo brings both cards back, Test P with its photo.
4c. **Address books.** The Test Person in "Cleanup test 2" doesn't join the Test Person group: the same person in two address books isn't a duplicate. Check "Also match cards in different address books" at the top of Duplicates: now it does (3 cards). Uncheck it again.
5. **Phone numbers.** The numbers show as `+1 555 ...`; Harry Example's UK number as `+44 20 7946 0958` (the `(0)` dropped, your grouping kept). Office Example's `555-444-1212 x123` is listed as having an extension and left alone. Apply. Open a card in the Address Book: the number changed, its type (mobile, work) didn't. Undo from Changes.
6. **Missing names.** Offered: "First Last" (from the email), "Nora Example" (from her first and last name), "Example Hardware" (from the organization), all checked; "Jdoe1987" (a one-word email guess) starts unchecked. Change one if you like, Apply, check the cards' display names.
7. **Chat addresses.** Chat Friend shows checked and locked (a chat address from elsewhere, never touched). Select "Phone Only", then Generate JMP.chat address. Open the card in the Address Book: its chat address is `xmpp:+15552223333@cheogram.com`, and the card can be edited and saved (no red field). Back in Contacts Cleanup, uncheck it and Apply: the address is gone. Try Select all phone contacts too, then Undo from Changes. On the Fix chat addresses tab: No Prefix is offered `xmpp:noprefix@example.org` and Old Jabber `xmpp:old.jabber@example.org`. Apply, then open No Prefix in the Address Book: its chat address can be saved now (before, the field was red).
8. **Theme.** View > Theme: Light Mode, Dark Mode, Match System. With Match System, switch Thunderbird between its light and dark theme (Add-ons and Themes > Themes): the tab follows.
9. **Chat contacts.** With your current OMEMO add-on (0.1.4, or Pro 0.3.0), expect the "Get OMEMO for Thunderbird" page, a bar with a Get OMEMO for Thunderbird button on Chat addresses, and a Get OMEMO for Thunderbird item in the sidebar under Chat (each opens OMEMO for Thunderbird's Gumroad page in your web browser): those versions don't answer other add-ons yet. "Learn about OMEMO Pro" (in the Chat contacts page's side panel) and OMEMO Pro on the About page open OMEMO Pro's Gumroad page. Then with OMEMO free 0.1.5 installed (it replaces Pro, same add-on id; reinstall Pro afterwards): the bar goes, the sidebar item reads OMEMO settings, and the Chat contacts page lists your accounts.
10. **Optional, real address books.** Check them again in the sidebar and look through the proposals without applying anything. Note any duplicate group that isn't one person, and any number that would come out wrong.

**Report:** what didn't match, and any Error Console line that mentions contacts-cleanup.
